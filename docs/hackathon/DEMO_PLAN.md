| Time | Picture | What it demonstrates |
| --- | --- | --- |
| 0–3 s | Animated receipt and title | One receipt becomes separate reimbursement requests. |
| 3–7 s | Desktop bill entry | Upload and manually confirm a synthetic £200 London bill. |
| 7–11 s | Desktop split review | Review equal USDC shares. |
| 11–15 s | Individual request view | Create a separate request for each payer. |
| 15–20 s | Mobile checkout | Select Zcash and use demo-only controls; success remains explicitly simulated. |
| 20–23 s | Organizer progress | Show simulated payment progress. |
| 23–25 s | Wordmark end card | Close on the product name and individual requests. |

The £200 London receipt is synthetic, uploaded footage. It is distinct from the built-in synthetic 200 AED sample in the reproducible local demo steps in the root README. The video shows sample UI and simulated settlement only: it creates no dry quote or live payment request, makes no wallet request or signature, moves no funds, and receives no provider settlement. OCR is not demonstrated. Keep those states described as simulations.
