# Demo media

These captures were produced from the local synthetic sample flow. They show UI states only; payment outcomes are simulated and no funded transaction is depicted.

- `home-mobile.png`: landing screen with the sample option and demo label.
- `checkout-demo.png`: fresh sample checkout before any attempt, with the demo label, payment choices and demo action. It contains no refund/history, QR code, account value, or private checkout URL.
- `organizer-progress-demo.png`: sample organizer view with one share paid in demo and two unpaid. The crop omits the receiving-address value and private links.
- `demo.mp4`: selected 25-second desktop/mobile video showing an uploaded synthetic £200 London GBP receipt, split review, separate requests, mobile checkout and simulated progress. This differs from the built-in 200 AED local sample. It uses an AI-generated fan-made Cartman voice, unaffiliated with South Park and its rights holders; third-party promotional rights are unverified.
